# 宿主渲染风景设置设计

## 状态

2026-09-17 批准实施。

## 问题

插件提供的 HTML Settings 页面无法满足风景合成要求。Electron
`WebContentsView` 是不透明的原生子界面；沙箱化 iframe 是独立的
Chromium 文档界面。两者都会在宿主拥有的风景背景与 Settings 控件
之间引入一块实心矩形。

## 决策

用宿主渲染的声明式 `scenicThemes` 目的地替换通用的插件 Settings
HTML 目的地。宿主在正常的 React Settings 树中渲染全部 DOM、样式、
布局、焦点行为、选中状态、滑块和 Apply 动作。插件只贡献经过校验
的元数据和已声明的主题资产。

首个实现支持 Nexus Scenic Themes 包。这是一条刻意窄化的契约，而不
是通用的插件 Settings UI 语言。

## Manifest 契约

`contributes.scenicThemes` 是一个可选对象，要求稳定 id、本地化
label、description、keywords、宿主支持的图标 token，以及按呈现
顺序的一到十二张主题卡片。每张卡片携带插件自有的已声明主题 id、
本地化名称与描述，以及该主题声明的一个预览资产。

宿主校验 `ui.settings`、`ui.theme`、卡片 id、本地化值、资产包含
关系、所有权，以及带类型、整数 `0..20` 边界的
`--nexus-backdrop-blur` 长度变量。其他变量和插件设置不能由该目的
地编辑。

通用 `settingsDestinations` HTML 入口从外观扩展能力中退役。插件的
`settings/` 目录被移除；不再有 iframe、自定义页面协议、桥接或第二
文档画布。

## 宿主界面与视觉所有权

宿主把风景目的地放在 Extensions 下，并直接在
`.settings-content-inner` 内渲染。在风景插件主题下，宿主画布、内容
包装和风景目的地包装都是透明的，因此同一个根背景在整个 Settings
中保持可见。

- 预览卡片使用声明的本地 `plugin-asset://` 图片、可读的叠层、选中
  描边 / 对勾，以及宿主拥有的焦点行为。
- 只有单独的卡片和模糊控件拥有实体界面；目的地没有外层面板或整页
  背景。
- 宿主拥有响应式网格布局、窄窗口重排、原生标题栏 / 控件保护、
  拖拽区域和降低透明度回退。

## 行为与数据流

1. 主进程校验每个已加载插件的风景元数据。
2. 宿主渲染卡片，并解析所选主题持久化的模糊值。
3. 选择卡片立即调用受限的插件自有主题选择 API。
4. range 输入接受 0 到 20 的整数，只改变本地草稿状态及其 `npx`
   output。
5. Apply 只对选中的自有主题调用既有的带类型变量 API 写入
   `--nexus-backdrop-blur`。
6. 保存成功后宿主刷新活动主题 CSS；失败则恢复已确认值并显示宿主
   toast。
7. 切换卡片会恢复每个主题已确认的模糊值；基础 / 其他插件主题遵循
   既有主题清理。

## 安全与生命周期

插件无法提供 HTML、CSS、JavaScript、选择器、组件、事件处理器、
任意动作或 iframe 内容。它们无法改变 Settings 几何、导航、拖拽
区域、原生控件或工作面板。未知路径、URL、变量、主题 id 和跨插件
引用都失败关闭。禁用、卸载或元数据无效会移除该目的地，并把活动
Settings 视图带回 General。

## 测试与验证

- SDK 校验拒绝格式错误的对象、未知 / 跨插件主题 id、未声明资产、
  重复项、未本地化字符串、不支持的变量，以及超出 1–12 的卡片数量。
- 主进程 / IPC 测试证明只有符合条件的已加载插件、声明资产重写、
  带类型变量所有权和生命周期清理。
- 渲染进程测试证明宿主渲染卡片 / range / Apply、透明外层所有权、
  响应式布局、选中无障碍、无 iframe 和无外层面板。
- 交互测试证明立即选中、仅草稿的滑块更新、仅 Apply 持久化、恢复、
  失败、基础 / 插件隔离、降低透明度和原生控件。
