# ADR 0005: 用户可安装的插件系统

- 状态: 已接受
- 日期: 2026-07-25
- 更新: 2026-07-25

## 背景

仅靠内置功能是不够的。用户需要安装和开发插件来扩展：

- 命令
- 面板
- agent 工具
- skills

## 决策

采用第一方**插件系统**：

- 基于目录的插件包
- `manifest.json` 贡献声明 + 权限声明
- 命令面板集成
- agent 工具注册支持
- 本地安装 / 启用 / 禁用 / 卸载
- 默认拒绝权限，需显式授予

## 理由

1. 无需 fork 应用即可实现用户定制
2. 比任意加载 Electron 主进程脚本更安全
3. 同时服务 UI 扩展和 agent 扩展
4. 为后续 marketplace 协议留出空间

## 后果

### 正面
- 产品界面可扩展
- 贡献模型清晰
- 与 skills/tools 生态对齐

### 负面
- 额外的架构和安全复杂度
- 需要管理 UI、校验和审计

## 范围控制

- MVP 优先做本地插件加载，不做 marketplace
- 第一批贡献点：commands / panel / agentTools / skills
- 插件默认隔离并按权限管控
