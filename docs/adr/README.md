# 架构决策记录（ADR）

ADR 记录那些不应被静默改变的决策。

[中文版 ADR 入口](/adr/README) 遵循相同的决策地图，并指向这些记录。决策
ID、状态和英文原文对两种语言环境都是事实来源。

## 格式

每份 ADR 包含：

- 状态
- 背景
- 决策
- 后果
- 替代方案（可选）
