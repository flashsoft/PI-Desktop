# ADR 0007: 插件分发包格式使用 .piplug (zip)

- 状态: 已接受
- 日期: 2026-07-25

## 背景

我们需要一种便于本地分享和 marketplace 下载的插件包格式。

## 决策

采用 `.piplug` 作为产品级分发扩展名。其内容为 zip 归档，根目录包含一个 `manifest.json`。

## 理由

1. 实现简单、跨平台
2. 便于做校验和 / 签名
3. 对开发者友好（可以本地解压检查）

## 后果

### 正面
- 工具链轻量
- 可以与本地目录包共享统一的校验逻辑

### 负面
- 必须防范 zip slip 和超大包攻击

## 约束

- 安装前必须进行路径安全检查
- marketplace 包至少必须提供 sha256
