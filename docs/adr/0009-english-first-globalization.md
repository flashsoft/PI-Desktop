# ADR 0009: 英语优先的全球化

- 状态: 已接受
- 日期: 2026-07-25

## 背景

PI-Desktop 面向全球用户和开放贡献。仅中文的产品界面会阻碍国际化采用和插件生态的发展。

## 决策

PI-Desktop 采用**英语优先**：

1. 产品 UI 默认语言：**英语**
2. spec、ADR、代码注释、提交信息、issue、插件文档：**以英语为主**
3. 从早期 UI 工作起就必须引入 i18n 框架
4. 其他语言（包括中文）是可选语言包，而不是事实来源

## 本地化规则

- 源字符串以英语维护
- 核心代码中不得硬编码非英文 UI 文案
- 语言包使用稳定的消息 ID
- 插件 manifest/文档建议使用英语；本地化字段后续可选

## 后果

### 正面
- 面向全球的基线
- 外部贡献更容易
- 插件生态的语言默认更清晰

### 负面
- 中文文案成为翻译层，而不是主要撰写格式
